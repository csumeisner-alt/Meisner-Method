---
name: Achievement design and triggers
description: Product rules for achievement presentation and unlock reliability.
---

Achievements should be one-time cosmetic rewards with brief, dismissible feedback. Do not add token payouts, streak pressure, or blocking celebrations. Award them from the product action itself, independently of Brew token/reward persistence or API success.

**Why:** achievements are meant to feel satisfying without distracting users, and a reward-service failure in preview must not hide an unrelated cosmetic unlock.

**How to apply:** when adding milestones, keep the catalog reviewable in Settings and verify the screen event triggers the achievement even when reward progress or remote services fail.

Show the selected achievement title flag once all 15 achievements are complete and selection data is ready; do not require Patriot Mode to be unlocked. If Patriot Mode is unlocked, the selected design replaces its default flag in the same header slot. Pride still requires the shared 30-view Biden quote threshold used by the Brew Bank.

**Why:** the user clarified that a selected flag should appear immediately, and that it replaces the Patriot Mode default when that mode is unlocked.

**How to apply:** gate the header flag on completed achievements and hydrated selection data, preserve valid saved selections, and read the Brew Bank's persisted quote-view count and shared 30-view threshold for Pride; do not create a parallel Pride counter.

Keep the Analyze “Meisner Method” title at its full size. When an achievement flag is unlocked, place it inline after the title and let it use the remaining header space.

**Why:** the user clarified that the brand title must never shrink to make room for the flag.

**How to apply:** do not use fit-to-width or text shrinking on the title; reclaim header spacing first, then size the inline flag from the remaining row width.

Do not preview or announce title-flag rewards before the achievement set is complete; keep the reveal a surprise.

**Why:** the user asked that the 15-achievement reward remain undisclosed until completion.

**How to apply:** hide the title-flag reward section until all 15 achievements are earned instead of showing a locked teaser.

When the 15th achievement is earned, show a brief, dismissible “Final Seal” celebration and let its main action open the title-flag choices.

**Why:** the user approved the Final Seal concept as the completion celebration.

**How to apply:** trigger only on the newly earned final achievement, keep it cosmetic and reduced-motion aware, and do not reveal flag rewards before completion.
