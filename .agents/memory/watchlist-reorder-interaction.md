---
name: Watchlist reorder interaction
description: The user's preferred watchlist drag and scroll interaction.
---

The user prefers long-pressing the main ticker card to reorder watchlist entries, rather than requiring the small drag handle. Ordinary swipes must continue scrolling, and alert/remove controls should remain separate taps.

**Why:** the user explicitly preferred the broader card-based reorder interaction while keeping scrolling unambiguous.

**How to apply:** Preserve this interaction when changing watchlist row layout or gesture recognition.
