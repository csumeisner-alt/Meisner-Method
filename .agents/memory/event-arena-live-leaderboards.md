---
name: Live Event Arena leaderboards
description: Product expectations and privacy boundaries for refreshing opted-in Event Arena standings.
---

**Rule:** The purpose of Event Arena leaderboards is for opted-in participants to see all players' current standings, refreshing every two minutes or when someone manually refreshes. Regular-event account snapshots must remain scoped to that isolated event account; never expose raw share counts or unrelated account activity.

**Why:** The user explicitly stated this is the point of the leaderboards and described the two-minute and manual refresh expectations.

**How to apply:** When changing leaderboard refresh, refresh every participant from available event-scoped data, bypass the automatic interval on a manual refresh, mark stale scores clearly, and keep private valuation data out of public responses.
