---
name: Dark Brew Token economy
description: Rules that keep Stamin Up rewards separate from the normal Brew Token game economy.
---

Dark Brew Tokens are a separate, persistent reward balance. When Stamin Up is armed, a win preserves the regular Brew Token stake and credits an equal winning award as Dark Brew Tokens; a loss remains a normal regular-Brew loss. Dark Brew Tokens are not spendable, wagerable, or losable.

**Why:** Stamin Up is intended as a collectible reward conversion, not a multiplier or a second bet. Mixing the balances would silently change the Central Bank’s regular odds and accounting.

**How to apply:** Keep every future Dark Brew feature outside regular Brew Token balance calculations and portfolio cash. If Dark Brew later becomes spendable, introduce an explicit dedicated redemption flow rather than allowing it into the reel stake.
